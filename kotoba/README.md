# 코토바 일본어 암기장 — 2026 재구축 버전

- 파일: `kotoba_cloud_ready.html` — 설치 없이 브라우저에서 열리는 단일 파일 웹앱.
- 포함된 단어: **86개** (확보한 옛 단어 43 + 2026년 11월 사진에서 추가된 40 + 옛 앱 화면에서 확인된 3). 기존 온라인 앱에는 전체 94개 단어가 표시됐지만 그 전체 목록이나 학습 기록은 원본 데이터에 접근할 수 없어 이 파일에 자동 이관되지 않았습니다.
- 기능: 양방향 플래시카드, 오답 복습, 4지선다, 학습 기록, 60일 뒤 복습, CSV/JSON 중복 병합, JSON 백업 및 로컬 저장, 선택적 Google 로그인/Firestore 동기화.

## 먼저 사용하기

1. `kotoba_cloud_ready.html`을 열면 Firebase 연결 없이도 로컬에서 바로 학습할 수 있습니다.
2. 학습 기록은 **현재 기기 브라우저**에 저장됩니다. 다른 기기와 자동으로 공유하려면 아래 클라우드 설정을 완료해야 합니다.
3. 온라인으로 쓰려면 정적 웹 호스팅 서비스(예: GitHub Pages)에 **파일 이름을 `index.html`로 바꿔 게시**합니다.

## PC·스마트폰 동기화 연결

1. [Firebase 콘솔](https://console.firebase.google.com/)에서 새 프로젝트를 만듭니다.
2. **Authentication → Sign-in method → Google**을 사용 설정하고, Firebase → Authentication → Settings → Authorized domains에 실제 배포할 도메인을 추가합니다. `file://` 주소에서는 Google 로그인 팝업이 차단될 수 있어 정식 HTTPS 사이트에서 이용하는 것이 좋습니다.
3. **Firestore Database**를 생성한 뒤 `firestore.rules`의 내용을 규칙 탭에 붙여넣고 게시합니다. 테스트 모드의 전체 공개 규칙을 유지하지 마세요.
4. 프로젝트 설정 → 내 앱 → **웹 앱**을 등록하고 표시되는 Firebase 설정 객체의 `apiKey`, `authDomain`, `projectId`, `appId` 값을 복사합니다. **서비스 계정 비밀키를 절대 입력하지 마세요.**
5. 코토바 앱에서 `설정·동기화` → 설정 JSON 붙여넣기 → 저장 → Google 로그인합니다. 다른 기기에서도 **같은 Firebase 프로젝트 설정과 동일한 Google 계정**으로 로그인하면 기록이 공유됩니다. (설정을 HTML 자체에 빌드하지 않은 경우, 기기마다 설정 입력이 필요합니다.)
6. 첫 연결 시 Firebase에서 오래된 기록이 있으면 더 최근 `updatedAt` 데이터를 우선합니다. 다른 기기에서 동시에 같은 단어를 수정하면 최신 기록이 반영됩니다.

## 데이터 복원 한계

- 기존 `chatgpt.site` 앱과 새 앱은 다른 주소라 브라우저 로컬 스토리지에 직접 접근해 기록을 옮길 수 없습니다. 기존 앱에서 JSON 백업 기능이 있다면 백업 후 새 앱의 `설정·동기화 → 백업 병합하기` 기능을 사용하세요.
- JSON 백업 형식이 다른 경우에는 구조에 맞춰 별도 변환이 필요할 수 있습니다. 기존 앱과 완전 호환되는 복원 기능은 검증되지 않았습니다.
- 현재 재구축 단어장은 기존 94개 중 **전체를 완전히 복원하지 못했습니다**. 추가 단어 목록이 나오면 앱의 CSV 가져오기 기능으로 중복 없이 합칠 수 있습니다.
- 실제 Firebase 연결, 인증, 다중기기 테스트, 배포는 아직 수행하지 않았으며 연동 준비 코드만 포함합니다.
